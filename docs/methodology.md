# 방법론

> 모든 데이터는 합성 데이터입니다 ([data_generation.md](data_generation.md)). 아래 가정값은 `src/config.py`, `src/kpi.py`에 상수로 정의되어 있습니다.

## 공통 가정

| 항목 | 값 | 근거 |
|---|---|---|
| 1인당 월 가용시간 | 140h | 월 소정근로 약 165h − 교육·회의·휴가·행정 등 비직접업무 약 15% |
| 휴직 비율 | 기준시점 비율을 과거에도 적용 | 휴직 이력 데이터가 없어 단순화 |
| 집계 기간 | 최근 12개월 | 분기말 계절성 1주기를 모두 포함 |

## Module A. 조직 생산성 진단 (`src/kpi.py`)

조직 d, 월 t에 대해:

```
필요시간        = task_count × standard_hours
가용인원        = actual_headcount × active_ratio
가용시간        = 가용인원 × 140h
업무부하율      = 필요시간 / 가용시간
1인당 처리량    = task_count / 가용인원
초과근무 추정   = max(0, 필요시간 − 가용시간) / 가용인원
```

**스냅샷 KPI** (최근 12개월 집계)

| KPI | 계산 | 비고 |
|---|---|---|
| 부하율 | Σ필요시간 / Σ가용시간 | 월별 비율의 평균이 아닌 합계의 비율 — 업무량이 많은 달에 가중 |
| 최대 월부하율 | max(월별 부하율) | 분기말 피크 확인용 |
| 과부하 개월수 | 부하율 > 1.0인 달 수 | |
| 1인당 월 초과(h) | 월별 초과근무 추정의 평균 | 부족분 전부를 초과근무로 메운다고 가정한 **상한** |
| 업무량 YoY | 최근 12개월 Σ필요시간 / 직전 12개월 − 1 | |
| 상태 | 부하율 > 1.05 과부하 / < 0.95 저활용 / 그 외 적정 | ±5%는 측정 오차·일시 변동을 감안한 허용폭 |

**주의**: 업무 1건의 의미가 조직마다 다르므로(운영 티켓 2.5h vs AI 과제 40h) *1인당 처리량은 조직 간 비교에 쓰지 않고* 조직 내 추이 확인에만 쓴다. 조직 간 비교는 시간 단위로 환산된 부하율로 한다.

**한계**: 표준처리시간이 고정이라 숙련도·자동화에 따른 생산성 변화를 반영하지 못한다. 실제 조직에서는 표준시간 자체를 주기적으로 재측정해야 한다.
